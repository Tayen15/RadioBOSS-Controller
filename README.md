# Radio Caster Request Bridge 🎙️📻

> **Aplikasi Web Penghubung Dashboard Caster dengan RadioBOSS Web Remote Control API.**  
> Memutar lagu/audio resmi dari YouTube Music langsung di RadioBOSS secara online (*live stream*) tanpa mengunduh file fisik ke penyimpanan harddisk.

---

## ✨ Fitur Unggulan

1. **Khusus Lagu Studio Master (Official Audio Only):**
   - Menggunakan integrasi YouTube Music Song Search (`filter="songs"` / *Auto-generated by YouTube*).
   - Terbebas dari suara dialog intro video klip, efek suara film/klip, outro skits, atau gangguan audio non-musik.
   - Metadata artis dan judul lagu terpisah rapi serta thumbnail cover album kotak 1:1 berkualitas tinggi.

2. **Anti-Expired Smart Stream Relay (`/api/stream/{video_id}`):**
   - URL CDN YouTube biasa akan kadaluarsa dalam 4–6 jam. Fitur Smart Stream Relay bertindak sebagai proxy stream dinamis yang selalu me-resolve token streaming baru secara instan saat RadioBOSS mulai memutar lagu.
   - Lagu di antrean bawah (`pos=-1`) tetap dapat diputar berjam-jam kemudian tanpa kendala *stream expired*.

3. **Format Audio Optimal untuk RadioBOSS (BASS Audio Engine):**
   - Memprioritaskan streaming container M4A / AAC (`bestaudio[ext=m4a]/bestaudio[acodec=aac]`) yang 100% stabil, minim latency buffering, dan kompatibel penuh dengan pustaka audio Un4seen BASS milik RadioBOSS.

4. **Integrasi RadioBOSS Web Remote API:**
   - **Putar Berikutnya (`pos = 1`):** Menyisipkan lagu tepat setelah lagu yang sedang aktif diputar.
   - **Antrean Paling Bawah (`pos = -1`):** Menambahkan lagu ke antrean paling akhir.
   - **Live Now Playing Monitor:** Memantau judul lagu yang sedang on-air, durasi berjalan, dan jumlah pendengar via API `playbackinfo`.

5. **Studio Master Caching & High-Res Artwork (Dual Guarantee):**
   - Mengunduh dan men-transcode audio YouTube Music secara background ke MP3 berkualitas 320 kbps dengan normalisasi loudness **EBU R128 (-14 LUFS, Target True Peak -1.5 dB)**.
   - Menyematkan ID3v2 APIC (*Attached Picture* Motion JPEG) dan menyimpan file sidecar `<nama_lagu>.jpg` berdampingan di folder cache sehingga RadioBOSS langsung menampilkan **Album Cover, Artis, Judul, Album, Tahun Rilis (Year), dan Genre** secara native di GUI-nya.
   - **Kustomisasi Lokasi Cache:** Lokasi penyimpanan cache dapat diatur bebas (misal ke partisi `D:\RadioCache` atau disk sekunder) melalui menu Pengaturan agar tidak membebani partisi `C:`.

6. **Dashboard Caster Modern (Next.js + Tailwind CSS):**
   - Tema *Dark Mode Studio* elegan dengan aksen cyan & emerald.
   - **Audio Preview di Headphone:** Caster dapat mendengarkan cuplikan audio langsung di browser sebelum mengirimkannya on-air.
   - **Lirik Lagu & Talking Points Announcer:** Modal terintegrasi yang menampilkan lirik lagu YouTube Music lengkap dengan panduan intro/outro timing untuk penyiar.
   - **Antrean RadioBOSS Live Inspector:** Menampilkan daftar lagu yang sedang mengantre di playlist RadioBOSS secara berkala.
   - **Riwayat Request (History):** Menyimpan daftar lagu yang baru dikirim ke antrean lengkap dengan tombol kirim ulang.

## 🛠️ Tech Stack

- **Backend:** Python (FastAPI), `ytmusicapi`, `yt-dlp`, `httpx`, `pydantic-settings`, `defusedxml`, `uvicorn`.
- **Frontend:** Next.js (App Router), TypeScript, Tailwind CSS, DaisyUI, Lucide Icons.
- **Desktop Runtime:** pywebview (Edge Chromium WebView2) & PyInstaller.
- **Target Integrasi:** RadioBOSS (semua versi dengan Web Remote Control HTTP API).

---

## ⚙️ Konfigurasi RadioBOSS

Sebelum menjalankan aplikasi, pastikan Web Remote Control di RadioBOSS sudah aktif:
1. Buka aplikasi **RadioBOSS**.
2. Masuk ke menu **Settings** / **Options** -> pilih tab **Network**.
3. Centang opsi **"Enable Web remote control"**.
4. Atur **Port** (default: `9000`).
5. (Opsional) Masukkan **Password** jika diinginkan.
6. Klik **OK** dan restart atau reload RadioBOSS jika diperlukan.

## 🚀 Cara Menjalankan

### Cara 1: Standalone Desktop App (Paling Direkomendasikan)
Cukup jalankan file executable siap pakai tanpa perlu instalasi Node.js, Python, atau konfigurasi file `.env`:
- Buka **`dist\RadioBOSSCaster.exe`** atau klik ganda **`run.bat`**.
- Aplikasi akan terbuka langsung sebagai program desktop Windows (Microsoft Edge WebView2).
- Masuk ke menu pengaturan dengan menekan ikon **⚙️ (Settings)** di pojok kanan atas untuk memasukkan password RadioBOSS pertama kali. Konfigurasi tersimpan otomatis di `%APPDATA%\RadioBOSSCaster\config.json`.

---

### Cara 2: Menjalankan Dalam Mode Development

#### 1. Frontend (Next.js dengan Bun)
```bash
cd frontend
bun install
bun run dev
```

#### 2. Backend (FastAPI)
```bash
cd backend
.venv\Scripts\activate
uvicorn app.main:app --port 8000 --reload
```

---

### Cara 3: Membangun Ulang File Executable (.exe)
Untuk mem-package ulang aplikasi menjadi satu file `.exe`:
```bash
# 1. Build frontend static export menggunakan Bun
cd frontend
bun run build

# 2. Package menggunakan PyInstaller
cd ..
backend\.venv\Scripts\python.exe desktop/build_exe.py
```
Hasil executable dan paket portable akan tersedia di folder `dist/`:
- `RadioBOSSCaster.exe` (Windows Standalone executable utama)
- `RadioBOSSCaster-Windows-x64.exe` (Windows 64-bit)
- `RadioBOSSCaster-Portable-Windows-x64.zip` (Windows 64-bit Portable Edition)

## 💼 Portable Edition (100% Self-Contained)

Aplikasi ini mendukung **Portable Mode** secara native:
- **Tanpa Instalasi:** Cukup ekstrak `RadioBOSSCaster-Portable-Windows-x64.zip` (atau buat file kosong `portable.txt` di folder yang sama dengan `.exe`).
- **Penyimpanan Lokal `./data/`:** Seluruh database SQLite (`radioboss_caster.db`), konfigurasi (`config.json`), audio cache, dan log siaran akan otomatis disimpan di folder lokal `./data/` tanpa menyentuh registry atau `%APPDATA%` sistem.
- **Dapat Dijalankan dari USB Flash Drive:** Anda dapat menyalin seluruh folder ke flash drive dan menjalankannya di PC studio mana pun secara langsung.

## 🐧 Dukungan Multi-Platform (Windows x64/x32 & Linux OS)

Radio Caster Request Bridge kini mendukung beragam arsitektur dan sistem operasi:
- **Windows 64-bit (`x64`)**: Standar untuk PC modern (Windows 10 / 11 64-bit).
- **Windows 32-bit (`x86`)**: Mendukung PC siaran radio studio lawas (Windows 7 / 8 / 10 32-bit).
- **Linux OS (Ubuntu, Debian, Fedora, Arch, Raspberry Pi OS 64-bit)**:
  - Menyediakan binary mandiri `RadioBOSSCaster-Linux-x64` dan paket `RadioBOSSCaster-Portable-Linux-x64.tar.gz`.
  - GUI native via WebKit2GTK dengan fallback otomatis membuka web browser default (Chrome/Firefox) jika berjalan di lingkungan tanpa GTK atau server/headless.
  - Skrip sekali klik untuk Linux: `./run.sh`.
