## CastDeck v1.0.0 — Pure Native Broadcast Studio

Rilis perdana **CastDeck** (sebelumnya *RCB Studio / Radio Caster Bridge Studio*), kini dibangun sepenuhnya sebagai aplikasi desktop native (**Zero-WebView**) yang lebih ringan, responsif, dan stabil untuk siaran langsung RadioBOSS.

### What's New
- **Pure Native Desktop Engine:** Migrasi penuh ke arsitektur native dengan startup instan, penggunaan RAM jauh lebih hemat, dan tanpa ketergantungan browser/WebView.
- **Rebranding Resmi ke CastDeck:** Pembaruan identitas aplikasi, installer `CastDeck-Setup-x64.exe`, serta pembersihan otomatis shortcut lama (*RCB Studio / Radio Caster Bridge*) saat upgrade.
- **Frameless Studio UI & Animasi Halus:** Header window frameless dengan kontrol native, dialog pengaturan split-pane dengan *autosave*, tab beranimasi halus, dan status bar desktop ringkas.
- **Pratinjau Audio Headphone Interaktif:** Pemutar pratinjau bawaan lengkap dengan *seekable progress bar* (klik & drag ke menit mana saja) dan *auto-stop* otomatis saat pindah lagu, antrekan ke RadioBOSS, atau tekan Play/Next.
- **Auto-Update Background:** Pengecekan dan pengunduhan pembaruan otomatis di background dengan tombol **Restart to Update** di header saat paket siap dipasang.
- **Dukungan Multi-Platform:** Tersedia installer **Windows x64** (`CastDeck-Setup-x64.exe`) dan paket **Linux x64** (`.deb` & `.tar.gz`).

### Key Fixes
- Perbaikan parsing durasi lagu YouTube Music lokal Indonesia (format titik seperti `4.58`) dan estimasi durasi MP3 untuk stream yang belum tersimpan di disk.
- Perbaikan bundel `yt-dlp` dan relay stream lokal (`:8000`) untuk pemutaran RadioBOSS & pratinjau headphone.
- Perbaikan layout responsif pada *Deck Persiapan*, dialog *Cue & Lirik*, dan dialog *Pengaturan*.

> **Catatan Upgrade:** Pengaturan RadioBOSS, koleksi *Set Playlist*, riwayat, dan cache lagu dari versi sebelumnya tetap terbaca otomatis tanpa perlu konfigurasi ulang.
