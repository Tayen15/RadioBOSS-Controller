# Product Requirements Document (PRD): Radio Caster Request Bridge

## User Persona
Radio DJ / Caster conducting live broadcasts on RadioBOSS who needs to fulfill song requests instantly from YouTube Music without downloading physical audio files to disk.

## Acceptance Criteria
1. Caster can search for songs by title/artist and receive ONLY official studio master tracks (Auto-generated by YouTube).
2. Caster can preview audio directly in the browser dashboard.
3. Caster can queue the track either to the end of the playlist (`pos=-1`) or as the next track (`pos=1`).
4. RadioBOSS receives and plays the stream reliably without expiration errors.
5. Dashboard displays live RadioBOSS connection status and Now Playing information.
6. Responsive and visually striking dark-mode UI with instant toast notifications.
