# Architecture Documentation: Radio Caster Request Bridge

## Overview
Radio Caster Request Bridge is a cross-platform desktop & standalone web application (supporting Windows x64, Windows x86/32-bit, and Linux) designed to connect a caster/DJ interface with RadioBOSS via its Web Remote Control HTTP API, enabling direct online streaming of YouTube Music studio master tracks without downloading files to local storage.

## Components & Topology
- **Desktop Runtime**:
  - Windows: Microsoft Edge WebView2 via `pywebview` (native borderless/frameless window without requiring Chrome or external browser tabs).
  - Linux: WebKit2GTK / Qt native window with automatic graceful fallback to system default browser (Chrome/Firefox/Brave).
  - Portable Mode: Automatically detected via `portable.txt` or `./data/` folder next to binary, storing all SQLite databases, configuration, audio cache, and logs completely self-contained without touching system appdata directories.
- **Backend**: FastAPI running in background daemon thread
  - `ytmusicapi`: Scrapes and queries official YouTube Music releases (`filter="songs"`), ensuring pure studio tracks (Topic / Auto-generated by YouTube) free of video intro dialogues, effects, and outro cuts.
  - `yt-dlp`: Resolves direct audio CDN streams (`bestaudio[ext=m4a]/bestaudio[acodec=aac]`) for 100% compatibility with RadioBOSS BASS engine.
  - **Transcoded MP3 Relay (`/api/stream/{video_id}.mp3`)**: Real-time FFmpeg transcoding into 320k CBR MP3 with embedded ID3v2 metadata, resolving RadioBOSS DASH container hangs.
  - `SettingsService` & `DatabaseService`: Multi-platform storage resolution (`./data` for Portable, `%APPDATA%/RadioBOSSCaster` on Windows, `~/.config/RadioBOSSCaster` on Linux).
  - `RadioBOSSService`: Handles remote HTTP API calls (`inserttrack`, `playbackinfo`, `setcasttitle`) with XML deserialization. Supports `radioboss_native` title template or custom `{artist} - {title}` formats.
- **Frontend**: Next.js Static Export compiled via **Bun**
  - Served directly from FastAPI static mount (`app.mount('/', StaticFiles)`).
  - Studio-grade pitch-black dark theme with Lucide icons.
  - In-app Settings Dialog (⚙️) with live connection tester and password toggle.
  - YouTube Music studio search, headphone audio preview, and one-click queue controls (`pos=-1`, `pos=1`).

## Communication Pattern
```
[Edge WebView2 Window]
         │ (HTTP :8000)
[FastAPI Backend Daemon (dist/RadioBOSSCaster.exe)]
         ├─-─> [Settings: %APPDATA%/RadioBOSSCaster/config.json]
         ├─-─> [RadioBOSS Web Remote API (:9000)]
         └─-─> [YouTube CDN / FFmpeg Transcoder]
```
